I'm Prabhav, an offensive security engineer and independent vulnerability researcher (OSWE, CRTO) specializing in software and network security.

My research focuses on hunting high-severity bugs within foundational open-source infrastructure. I systematically audit the low-level components modern tech stacks rely on, such as the web servers and reverse proxies that route global traffic, the parsers and serializers that ingest untrusted data, and the compilers and core runtime libraries powering execution environments. I'm drawn to subtle semantic flaws and state-machine edge cases where small implementation oversights cascade into high-severity security vulnerabilities.

This blog exists to detail the madness behind the research and break down some interesting concepts I learn along the way.
